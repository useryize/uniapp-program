| 用途 | 色值 |
|---|---|
| 墨黑（主色 / 强调块） | `#0A0A0A` |
| 酸性黄（主 CTA / 高亮） | `#FFD500` |
| 价格红（金额 / 折扣 / 紧张库存） | `#E24B4A` |
| 纯白（页面底 / 次级按钮） | `#FFFFFF` |
| 浅灰（分组底 / 禁用） | `#F2F2F2` |
| 次要文字 | `#8C8C8C` |
| 推荐条底 / 紧张库存底 | `#FFF8D9` / `#FFF1F1` |

### 字体

| 用途 | 字体 | 说明 |
|---|---|---|
| 价格、英文装饰、数字 | **Archivo Black** | 大号价格、倒计时、编号 |
| 英文标牌（NEW DROP 等） | **Bungee** | 短标签，字距 0.4–1px |
| 中文标题 / 正文 | **Noto Sans SC** | Black 用于标题，Regular/Medium 用于正文 |
| 数字 / 英文正文 | **Inter** | 表头数字、订单号 |

### 尺寸与边框

- 页面基准 `375 × 812`，左右安全边距 `16px`，列表块间距 `10–12px`
- 顶部导航 `56px`，状态栏 `62px`（深色页）/ 浅色页同高
- 底部操作栏 `64–72px`，TabBar `96px`（62 胶囊 + 安全区）
- 所有按钮 / 卡片 **2px 纯黑描边、圆角 0** —— 街头感来自硬边，不用圆角
- 主 CTA 黄底黑字，次级白底黑框，禁用 `#BFBFBF`
- 图标全部为 **SVG 线性图形**，2px 描边，无 emoji / 字体图标

## 五、如何重新导出

设计稿改动后，需要重新导出覆盖本地文件。跟我说「重新导出设计稿」即可，或者自己在 Ardot 里操作：

- **PDF**：文件 → 导出 → PDF（会按画布从上到下、从左到右合并所有 Frame）
- **PNG**：选中单个 Frame → 导出 → PNG → 选 2x

导出的 PNG 建议按 `页码-页面名.png` 命名，和现有文件保持一致，方便对照。

## 六、服装电商的关键交互约定（开发重点）

这部分是设计稿里容易被忽略、但直接影响转化和退换货率的逻辑，实现时请对齐：

1. **尺码是核心决策点**，不是规格。尺码助手、尺码表入口要出现在**详情页 / 规格面板 / 购物车**三处。
2. **售罄尺码保留展示**，置灰 + 加遮罩 + 文字划掉，**不要隐藏**——稀缺性需要被用户看见。
3. **规格入口悬浮吸底**（详情页 40px 条），页面下滑时始终可见，避免用户回滚找尺码。
4. **规格面板**为可滑动大面板（600px 高），含尺码助手入口，底部双按钮：加购 + 立即购买。
5. **关闭面板再打开要回显上次已选规格**；颜色切换即时刷新主图。
6. **购物车内可直接改规格**（点规格区唤起面板），并提供凑单提示引导满 99 包邮。
7. **限量款三态**：即将发售（倒计时 + 订阅）/ 正在发售（剩余库存 + 抢购）/ 已售罄（到货提醒）。
8. **尺码档案持久化**，跨商品复用推荐结果，降低退换货率。

## 七、开发注意事项

- **尺码档案需要新增用户字段**：身高 / 体重 / 体型（Y/A/B/C），否则跨商品推荐无法复用。
- **发售提醒依赖订阅消息能力**：mock 阶段可先做静态展示，不接推送。
- **金额口径**沿用项目现有约定：整数「分」存储传输，展示层用 `fen2yuan()` 转元，前端不计算金额。
- **运费规则**：满 ¥99 免邮，否则 ¥8（`pages/mall/config.js`，PRD 中为待业务确认项 Q7）。
- 设计稿里的商品图取自 `assets/`，接入真实接口后应替换为 CDN 图，字段对应 `goods.cover`。
