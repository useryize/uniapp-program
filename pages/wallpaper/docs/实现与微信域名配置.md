# 壁纸模块实现与微信域名配置

更新：2026-11-04。交互参考 [V2 原型](../design/wallpaper-gallery-v2.html)。

## 已实现的功能

| 页面 | 功能 |
| --- | --- |
| 精选 | 今日主图、氛围分类、城市合集、精选横向列表、下拉刷新 |
| 探索 | 关键词搜索、分类、排序、近似色调筛选、分页加载、空状态与失败重试 |
| 详情 | 原图／锁屏／桌面预览、左右切图、作品信息、本地收藏、保存原图到相册 |
| 收藏 | 使用 `uni` 本地存储，保存和取消收藏；不跨设备同步 |

页面只通过 `pages/wallpaper/api/index.ts` 访问数据。`api/source/commons.ts` 调用 Wikimedia Commons 的 MediaWiki API，精选图片按文件名维护；探索使用搜索结果，并筛掉非 CC0、非 JPEG/PNG、宽度不足 1000 像素和非竖屏图片。色调筛选由英文搜索词近似实现，不能保证每张图的颜色完全匹配。图片详情保留作者、许可与原始文件页信息。保存功能下载原图后调用 `uni.saveImageToPhotosAlbum`，在 H5 中仅提示到小程序操作。

## 微信小程序后台需要新增的域名

这 **3 个域名都是本次新增**，是当前代码直接使用的域名。请在微信公众平台的小程序后台分别添加到对应的服务器域名类型中；只配 `request` 不足以显示和保存图片。

| 新增域名 | 后台配置类型 | 当前用途 | 代码位置 |
| --- | --- | --- | --- |
| `https://commons.wikimedia.org` | `request` 合法域名 | 查询精选、搜索和图片许可元数据 | `api/source/commons.ts` |
| `https://thumb.wikimedia.org` | `downloadFile` 合法域名 | 列表、首页展示 Commons 返回的缩略图 | `imageinfo.thumburl`，由 Commons API 返回 |
| `https://upload.wikimedia.org` | `downloadFile` 合法域名 | 详情原图展示和保存到相册 | `imageinfo.url`，由 Commons API 返回 |

请以微信开发者工具的 Network 面板再核对 API 实际返回的图片域名；若 Commons 后续改变图片托管域名，需要同步更新白名单。正式小程序还受微信的 HTTPS、域名所有权及备案等审核要求约束。**能在开发者工具关闭域名校验后访问，不代表真机或发布版本可访问**。如果微信后台不能添加这些境外域名，需要接入你自己符合微信要求的已备案服务域名，并将 API 与图片请求改为走该服务；当前仓库尚未提供这个中转服务，因此发布可用性要以后台配置和真机验证为准。

## 本次未新增或已移除的域名

- `https://api.pexels.com`：旧壁纸实现所用，现已移除其调用与 H5 代理，壁纸模块无需继续配置。若其他模块未来引用，应另行核对。
- 本次没有新增云端收藏、登录、统计或自有图片服务域名。

## 自测建议

1. 在微信后台配置上表中的 `request` 和 `downloadFile` 域名，重新编译小程序。
2. 真机打开精选和探索，检查缩略图、原图、下一页加载。
3. 在详情页切换预览、收藏、保存到相册，并检查首次授权及拒绝授权后的提示。
4. 如域名配置被拒绝或请求失败，先确认微信后台的域名资格，再接入自有代理／图片服务，不要依赖开发者工具的「不校验合法域名」开关。

本地静态检查：最终代码的 `npm run typecheck` 已通过；H5 和微信小程序构建曾在最后一处分页修正前通过。按你的安排，最终构建由你运行。此前构建输出有项目现存的 Sass `@import` 弃用提示。本文的域名配置和真机流程尚需在你的微信小程序账号中验证。

参考：[MediaWiki Search API](https://www.mediawiki.org/wiki/API:Search)、[Imageinfo API](https://www.mediawiki.org/wiki/API:Imageinfo)、[Commons 复用说明](https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia)。
