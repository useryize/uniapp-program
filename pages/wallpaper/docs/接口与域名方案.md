# 壁纸模块：图片接口与微信域名方案

> 本文保留前期数据源调研。当前已落地的接口和微信后台实际配置清单，请以[实现与微信域名配置](实现与微信域名配置.md)为准；下文的 Openverse、Wallhaven 仍是候选方案，未接入运行时代码。原文所述 Pexels 代码已移除。

> 调研整理：2026-11-04。适用场景：个人非商用的壁纸小程序。接口免费、个人使用和图片允许再分发是不同的判断，正式提供下载前仍需核对每张图片的授权。

## 目标与原型

交互原型：[画间 V2](../design/wallpaper-gallery-v2.html)（另有[静白画廊 V1](../design/wallpaper-gallery.html)供比较）。新版包含首页精选、分类、搜索、双列图片流、详情预览、锁屏／桌面效果、连续切图、收藏和保存。原型图片是内置 SVG 示意图，**没有接入任何外部图片接口**。交互细节见[交互设计 V2](交互设计-v2.md)。

当前壁纸代码在 `home/`、`find/` 中直接调用 `utils/request.ts`，使用 Pexels。后续接入应在本模块建立 `api/index.ts` 统一出口，页面只从该出口取数据。

## 数据源结论

| 来源 | 能提供什么 | 本项目建议 |
| --- | --- | --- |
| [Openverse API](https://docs.openverse.org/packages/js/api_client/index.html) | 开放许可图片搜索、详情、缩略图及作者／许可字段 | **候选图片发现工具**。优先筛选 CC0；其[服务条款](https://docs.openverse.org/terms_of_service)明确不核验内容的许可状态，不能把搜索结果直接视为已授权壁纸。 |
| [Wikimedia Commons API](https://commons.wikimedia.org/wiki/Commons:API/MediaWiki) | 图片文件信息和 `extmetadata` 中的许可、作者信息 | **单图核验与精选图库来源**。逐张检查原始文件页；CC BY 等许可仍需按要求署名。[复用说明](https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia/licenses/en) |
| [Wallhaven API](https://www.whvn.cc/help/api) | 壁纸搜索、分辨率、缩略图及原图地址；公开安全内容可免密钥检索 | **可选探索源**。接口开放不代表每张投稿作品都可由本小程序再分发或供下载，未核实单图权利前不作为正式图库。 |

暂不采用以下来源作为独立壁纸下载功能的数据层：

- **Pexels**：当前项目已接入，但其[API 指南](https://www.pexels.com/api/documentation/)明确不允许用 API 复制其核心功能，包括提供 Pexels 内容的壁纸应用。个人非商用不改变该限制。
- **Unsplash**：其[API 指南](https://help.unsplash.com/en/articles/2511257-guideline-replicating-unsplash)同样明确排除下载 Unsplash 图片的壁纸应用。
- **Pixabay**：其[使用条款](https://pixabay.com/service/terms/)限制将基本未改动的内容作为独立壁纸分发。

## 功能与接口对应

| 功能 | 数据需求 | 首版实现 |
| --- | --- | --- |
| 今日精选、本周推荐、分类 | 审核后的图片目录，包含标题、分类、缩略图、原图、作者、来源、许可 | 由项目维护精选清单；不把第三方搜索结果直接推送为首页内容。 |
| 发现页搜索和分页 | Openverse `GET /v1/images/`，例如按关键词、许可和页码检索 | 作为候选图检索；小程序正式版优先查询自己的已审核图库。 |
| 图片详情与来源 | Openverse 详情数据；Commons 文件页及 `imageinfo&iiprop=extmetadata` | 入库前人工核对许可；前端展示作者、来源页面和许可。 |
| 锁屏效果 | 无网络接口 | 前端在图像上叠加模拟日期与时钟。 |
| 收藏 | 图片 ID 列表 | 首版用 `uni.setStorageSync`；需要跨设备同步时再增加用户收藏接口。 |
| 保存到相册 | 已审核图片的原图地址 | `uni.downloadFile` 后调用 `uni.saveImageToPhotosAlbum`，并处理相册权限与下载失败。 |

精选清单至少保存 `id`、`title`、`category`、`width`、`height`、`thumbnailUrl`、`imageUrl`、`creator`、`sourcePageUrl`、`license`、`licenseUrl` 和核验时间。优先选择适合手机的竖图，避免把横图简单裁切后当作手机壁纸。

## 微信小程序域名：哪些是新建议

以下为**代码现状与接入候选**，并不代表域名已在微信公众平台后台配置。实际后台配置需由管理员核对。

| 域名 | 状态 | 需要配置的白名单 | 条件 |
| --- | --- | --- | --- |
| `https://api.pexels.com` | **现有代码引用** | `request` | `utils/request.ts` 当前使用；迁移后不再需要。 |
| `https://api.openverse.org` | **新建议** | `request` | 仅当小程序直接请求 Openverse 时。其返回的图片可能托管在不同来源域名，不能只配置这一项就解决图片显示／下载。 |
| `https://commons.wikimedia.org` | **新建议** | `request` | 仅当小程序直接查询 Commons 元数据时。 |
| `https://upload.wikimedia.org` | **新建议** | `downloadFile` | 仅当小程序直接加载或下载 Commons 图片时。 |
| `https://wallhaven.cc` | **新建议，可选** | `request` | 仅当启用 Wallhaven API 时。 |
| `https://th.wallhaven.cc` | **新建议，可选** | `downloadFile` | Wallhaven API 示例中的缩略图域名。 |
| `https://w.wallhaven.cc` | **新建议，可选** | `downloadFile` | Wallhaven API 示例中的原图域名。 |
| `https://<你的接口域名>` | **新建议，占位符** | `request` | 采用自有服务端方案时，替换为真实 HTTPS 域名。 |
| `https://<你的图片域名>` | **新建议，占位符** | `downloadFile` | 审核后的图片放在自有存储／CDN 时，替换为真实 HTTPS 域名。若与接口同域名，同一域名仍需按使用方式分别配置。 |

`request` 与 `downloadFile` 是不同的白名单。远程图片展示和保存应在真机验证；开发者工具中的「不校验合法域名」仅适合本地调试。[uni-app 网络文件文档](https://uniapp.dcloud.net.cn/api/request/network-file.html)、[腾讯云小程序下载域名配置指引](https://docs.cloudbase.net/lowcode/practices/miniapp-guide/downloadfile-guide)。小程序后台对域名的 HTTPS、备案等要求也要在选择自有域名和部署地点时核对。

## 推荐接入顺序

1. 用 Openverse 找候选图，并在原始页面核对许可、作者、分辨率和可用性；将通过审核的图片录入精选清单。
2. 将精选清单及图片放在自有服务端／图片存储。小程序只调用自己的 API，避免第三方图片域名不断变化。
3. 在 `pages/wallpaper/api/` 建立类型、请求封装和 `index.ts` 统一出口，再替换页面中对 `utils/request.ts` 的直接引用。
4. 实现列表、详情、收藏和保存；配置真实 `request`／`downloadFile` 域名后在微信真机逐项验证。

当前 `utils/request.ts` 将 Pexels API key 写在客户端源码中。迁移数据源时应移除该密钥；如果未来使用需保密的第三方凭据，应只放在服务端。
