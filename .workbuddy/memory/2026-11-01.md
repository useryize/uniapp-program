## 音乐播放模块（pages/music）— 调研 + 交互规格

**需求**：做音乐播放小程序（类网易云/汽水），先调研免费音乐接口。定位选定「独立音乐发现」。

### 接口调研结论（真实请求实测，非文档抄录）

| 接口 | 能播完整歌 | 免费 | 中文曲库 | 实测 |
|---|---|---|---|---|
| **Audius** `api.audius.co/v1` | ✅ 302→307→CDN | ✅ 50万次/月，免 Key | ⚠️ 有但是盗版搬运 | 通 |
| iTunes Search | ❌ 仅30s试听 | ✅ 免Key | ❌ 中国区音乐为空 | 通（US区正常） |
| Deezer | ❌ 仅30s试听 | ✅ 免Key | ⚠️ 欧美 | ❌ SSL直连失败，国内不可用 |
| MusicBrainz | ❌ 只元数据 | ✅ | 一般 | 通 |
| 网易云 Enhanced（自建） | ✅ 全 | ✅ MIT | ✅ 最全 | 违反ToS，审核过不了 |
| 汽水音乐 | — | ❌ **无任何开放 API** | — | 不可行 |

**Audius 能力清单**：榜单（week/month/allTime × 30+曲风）、专题歌单 `/playlists/trending`、歌单曲目、搜索（歌曲/歌单/艺人）、艺人主页、**评论（含 `track_timestamp_s` 时间戳）**。
**缺失**：歌词 404、相似推荐 404、用户系统需 OAuth PKCE。

### 三个致命坑（必须记住）

1. **`genre=All` 返回 0 条** —— 「全部」选项必须省略该参数，不能传 All
2. **`api.audius.co` 无 ICP 备案** —— 微信小程序 request 合法域名实时校验备案，未备案直接 `url not in domain list`。**小程序端必须走自建中转，H5 可直连**
3. **中文歌是用户搬运的盗版** —— 搜「周杰伦」5 条全来自同一账号「Jay 周杰伦」，随时下架。不能按中文流行曲库规划产品

### 性能基线

- API：1.6–3.9s（10/10 成功，均值 2.5s）→ **必须骨架屏**
- 音频首字节 **4.8s**，码率 ~48KB/s（audio/mpeg，206 分段）
- 音频直链签名**短期有效，不可缓存落库**，每次播放前现取

### 音频上下文选型（关键技术决策）

- 小程序：`uni.getBackgroundAudioManager()` —— **只有它支持后台+锁屏播放**
  - `src` 赋值即自动播放 → 「暂停后继续」只能调 `play()`，不能重设 src
  - `title`/`singer`/`coverImgUrl` 必填，否则锁屏空白
  - 单实例，切歌必须先 `stop()` 再赋新 src
- H5：`uni.createInnerAudioContext()`
- **manifest.json 需新增 `mp-weixin.requiredBackgroundModes: ["audio"]`**（当前缺失）

### 产出

`pages/music/docs/交互规格说明书-音乐.md`（588 行，v1.0）

7 页路由（P0: home/player/playlist/chart；P1: search/artist；P2: library）+ 7 个组件。
核心设计：播放器单例（模块级 reactive，项目无 vuex/pinia）、五态状态机 `idle|loading|playing|paused|error`、三态播放模式、**评论时间轴弹幕**（Audius 独有字段做差异化）、可解释推荐（无相似推荐接口，用「同曲风/同艺人/同期上榜」拼理由）。

视觉骨架：深夜黑胶 —— 底 `#0A0A0C`、主色荧光青 `#00E0B8`、次强调橙红 `#FF5A36`，播放页取封面主色做双层径向渐变+40px 模糊。与商城 Y2K 酸性黄、壁纸轻白、天气深蓝刻意区隔。

### 两个必须解决的问题（都给了方案）

**1. Banner 没有横幅图源**：Audius 只给 1000×1000 方图。**直接裁成横幅会砍掉封面主体**（人物/字标居中，横切砍头、竖切切边）。方案 = 三层构图：
- 底层：同一张封面 `cover` 铺满 + `blur(20px)` + 黑 55% 遮罩
- 左：清晰的 88×88 圆角 12 方图
- 右：类型胶囊 → 标题 18px 两行 → 理由 12px
- 尺寸 343×152，4 张，4.5s 自动轮播，指示器用 4 条短横线（圆点在深色底上太弱）
- 取数规则写死：本周榜第1首 / 歌单trending第1 / 用户top1曲风第1首 / 歌单trending第2

**2. 每日推荐没有个性化接口**：本质不是算法聪明，而是三件事——①每天不一样 ②同一天不变 ③听过的会消失。三件事只需本地数据。
- 确定性抽样：`seed = hash(dateKey + deviceSeed)`，**与请求时刻无关** → 同一天多次进入结果逐条一致
- 候选池 top3曲风×(week+month)各20 + 全局week20 → 剔除 recentTrackIds/favTrackIds/gated
- 配额 top1 40% / top2 25% / top3 15% / 全局 20% = 30 首
- 理由生成（可解释性出口）：`因为你常听{曲风}` / `你听过{艺人}的N首` / `本周新上榜` / `今天值得一听`
- **下拉刷新故意无效**（toast「今天的推荐明天更新」）—— 守「同一天不变」的信任感

## 音乐域名实测（2026-11-01，重要）

**封面图域名是分散的随机第三方节点**，实测 5 首歌落在 6 个不同域名：
`audius-content-3.figment.io` / `audius-creator-12.theblueprint.xyz` / `cn0.mainnet.audiusindex.org` / `v.monophonic.digital` / `val013.open-audio-validator.com` / `val017.open-audio-validator.com`
→ Audius 去中心化架构，曲目存在哪节点图就在哪域名。**downloadFile 白名单无法穷举**。

**音频**：`api.audius.co/v1/tracks/{id}/stream` → 302 `creatornode.audius.co/tracks/cidstream/{cid}?signature=` → 307 同域名补 `skip_play_count` → 200 audio/mpeg。域名固定。

**结论：音乐只能走自建中转，只配 1 个域名**（`https://api.你的域名.com`），路径：
- `/v1/audius/*` → api.audius.co/v1/*
- `/v1/img?u=` → 封面图代理（**必须**，否则小程序封面全挂）
- `/v1/stream/:id` → 透传 302，**中转层不可跟随 302**（否则整首歌下载到服务端内存）

⚠️ 天气模块的做法**不可套用**：天气可直接配源站域名（境外域名不强制备案），音乐因图片域名不可穷举必须中转。

文档：`pages/music/docs/域名与备案.md`（含 Node/Nginx 中转代码、格式硬要求、真机验证清单、报错速查）

| 项 | 内容 |

| 页面/组件 | 19 个 `.vue` 全部改为 `<script setup lang="ts">`，import 去掉 `.js` 后缀 |
| 配置 | `tsconfig.json`（strict / moduleResolution bundler / types: ["@dcloudio/types"]） |
| 脚本 | `npm run typecheck` → `node node_modules/typescript/lib/tsc.js --noEmit` |

**踩坑**
1. `tsc` 7.x 已移除 `baseUrl` 选项，paths 直接用相对路径 `"@/*": ["./*"]`
2. 索引签名类型要放宽到 `string | number | boolean | undefined`，否则 `force?: boolean` 传不进 `Record<string, ...>`
3. npm 装包因 `~/.npm` 权限报错（`sudo chown -R 501:20 ~/.npm` 可修），但包已落地；`.bin/tsc` 链接缺失，故 script 直接调 `node_modules/typescript/lib/tsc.js`
4. **tsc 不检查 `.vue`**（未装 vue-tsc），页面的类型错误不会被捕获，只保证可编译。要严格检查需 `npm i -D vue-tsc` 后跑 `vue-tsc --noEmit`
