## 第二轮：按市面成熟实践重构交互逻辑（用户反馈后）

- 用户反馈：**不要参考现有项目定方向**，应参考市面成熟交互逻辑 / GitHub 实现。
- 调研来源：
  - 人人都是产品经理《设计总结：商品规格选择弹窗》——面板唤起方式、固定/可滑动两型、
    规格三态视觉、尺码推荐/尺码助手/尺码表三件套。
  - 人人都是产品经理《优化"商品规格选择"面板》——面板四大分区、多联选择器、颜色-尺码库存联动。
  - 得物 / 识货 / Nice 竞品分析——尺码档案、默认尺码、尺码推荐。
  - SNKRS / 滔搏运动——发售日历、倒计时、抽签、发售提醒、补货提醒、3D/AR 试穿。
  - macrozheng/mall-app-web 等 GitHub 电商项目——页面组织方式。
- 核心判断：**服装电商 ≠ 通用商城**。通用商城的核心是"规格"，服装的核心是"尺码决策"；
  潮牌的核心是"发售机制与稀缺性"。上一版套用的是通用商城骨架，只换了视觉皮肤。
- 重构内容：
  - 新增 16 号页「尺码助手/尺码表」：身高体重体型录入 → 推荐尺码卡 + 完整尺码表（推荐行黄底高亮）。
  - 新增 17 号页「发售日历」：即将发售(黄/倒计时/订阅) / 正在发售(红/剩余库存/抢购) /
    已售罄(灰/到货提醒) 三态。
  - 详情页：加尺码推荐条、售罄码保留置灰划线、规格入口悬浮吸底(40px)、紧张库存文案。
  - SKU 面板：高度 520→600px 可滑动、加尺码助手入口、加紧张库存提示条、售罄码保留。
  - 首页：分类金刚区改为「发售日历 / 尺码助手 / 联名专区 / 全部商品」四入口。

  - 个人中心：加尺码档案入口 + 发售提醒卡。
